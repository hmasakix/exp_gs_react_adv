# AIイベント朝礼（仮称）

## これは何？
初めて顔を合わせるイベントスタッフ向けの、個人用朝礼Webアプリです。
全体朝礼（対面）とは別に、アルバイトスタッフ一人ひとりが
「笑顔」と「その日の伝達事項3つ」を確認します。
カメラで笑顔率を測りながら、伝達事項を声に出して復唱すると、AIがひと言返してくれます。
記録は履歴ページにスタッフ名つきで残り、管理者が実施状況を確認できます。

## 使った技術
- Next.js（App Router）/ TypeScript
- Groq（AIのフィードバック・音声の文字起こし）
- face-api（表情の判定）
- Neon + Drizzle（データベース）
- Clerk（ログイン）
- Resend（メール配信）
- Vercel（公開）

## 工夫したところ
- 授業で作ったAPIと画面を活かし、役割を置き換えて朝礼ツールにした
  （お題 → 伝達事項3つ、回答 → 声での復唱、履歴 → 管理者の実施確認）
- 声に出して復唱することで、伝達事項が記憶に残るようにした（間違いが少なくなる）
- 笑顔率を測って、笑顔で1日をスタートできるようにした

## やり残したこと
- 伝達事項3つを管理者画面から入力できるようにしたい（今はコードに直接書いている）
- AIの返事を「3つ正しく復唱できたか」の判定に特化させたい
- スタッフ名を専用の入力欄にしたい（今はメモ欄を使っている）

## 動かし方
`.env.local` に次の変数が必要です（値はここには書きません）。
- GROQ_API_KEY
- DATABASE_URL
- NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY
- CLERK_SECRET_KEY
- RESEND_API_KEY
